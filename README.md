# QR-меню ресторана «Istanbul»

**Меню онлайн:** https://sariofficial23.github.io/qrmenu/
**Готовые QR-коды для печати (столы 1–20 + общий):** [`print/qr-tables.pdf`](print/qr-tables.pdf)
**Сделать QR для других столов:** https://sariofficial23.github.io/qrmenu/qr.html
**Приложение для планшета (Android):** https://github.com/Sariofficial23/qrmenu/releases/latest/download/Istanbul-Menu.apk

Бесплатное электронное меню: гость сканирует QR-код на столе → видит меню в телефоне
→ добавляет блюда в корзину → показывает экран «Заказ» официанту.

- 3 языка: русский, узбекский, английский
- Цены в сумах, обслуживание % считается автоматически
- Номер стола берётся из QR-кода
- Корзина не пропадает при перезагрузке страницы
- Работает без интернета после первого открытия; можно «установить» на планшет как приложение
- Без сервера, без базы данных, без абонплаты — **0 сум**

## Файлы

| Файл | Что это |
|---|---|
| `menu.js` | **Ваше меню** — название, категории, блюда, цены. Меняете только его |
| `qr.html` | Печать QR-кодов для столов |
| `index.html`, `app.js`, `styles.css` | Сам сайт (трогать не нужно) |
| `sw.js` | Офлайн-режим |

## 1. Публикация (уже сделано)

Сайт публикуется бесплатно через GitHub Pages из ветки **`gh-pages`**.
Любое изменение в ветке `gh-pages` появляется на сайте через 1–2 минуты.

## 2. Заменить меню на своё

Откройте `menu.js` в ветке `gh-pages` прямо на GitHub (значок карандаша), поменяйте названия и цены → **Commit changes**.
Сайт обновится сам через 1–2 минуты.

- Цена — просто число: `price: 45000`
- Блюдо закончилось — добавьте `hidden: true`
- Своё фото: загрузите файл в папку `img/` (лучше `.webp` или `.jpg`, до 150 КБ) и укажите `img: "img/plov.jpg"`
- Хотите, чтобы гость мог отправить заказ в Telegram официанту/админу — впишите ник в `telegram: "nick"`

После больших изменений поменяйте в `sw.js` строку `qrmenu-v1` на `qrmenu-v2` — так у всех гостей сразу загрузится новая версия.

## 3. Распечатать QR-коды

Готовый файл: `print/qr-tables.pdf`. Для другого количества столов откройте `https://sariofficial23.github.io/qrmenu/qr.html`, укажите номера столов (например, с 1 по 20) → **Печать**.
На каждом QR свой номер стола. Режьте и ставьте на столы (в подставку или под стекло).

## Приложение для планшета

### Способ 1 — из Chrome (рекомендуется, без предупреждений)
1. На планшете откройте в Chrome https://sariofficial23.github.io/qrmenu/
2. Нажмите золотую кнопку **«Установить»** вверху меню
   (или ⋮ → **Установить приложение** / **Добавить на главный экран**).
3. Появится иконка **Istanbul** с тюльпаном: открывается на весь экран,
   работает без интернета, меню и цены обновляются сами.

Так устанавливается встроенными средствами Android — без «неизвестных источников»
и без предупреждений Play Protect.

### Способ 2 — файл APK (запасной)
https://github.com/Sariofficial23/qrmenu/releases/latest/download/Istanbul-Menu.apk

Android предупредит об установке «не из Play Market» — так он ведёт себя с любым
приложением, скачанным по ссылке. Новая версия APK собирается автоматически
(GitHub Actions → «Android app»).

### Play Market
Регистрация разработчика в Google Play — разово 25 $. Для личного аккаунта Google
перед публикацией требует закрытое тестирование (около 12 тестировщиков, 14 дней);
аккаунт организации этого не требует, но нужен номер D-U-N-S.
